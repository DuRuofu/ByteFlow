

### 目标

基于 **Vue 3 + Web Serial API** 实现一个浏览器端串口调试工具，用于嵌入式开发调试。

------

### 运行环境

- Chrome / Edge（支持 Web Serial API）
- 纯前端，无后端

------

### 核心功能

1. **串口管理**
   - [x] 选择串口
   - [x] 配置波特率
   - [x] 打开 / 关闭串口
   - [x] 显示连接状态
2. **数据接收**
   - [x] 实时接收并显示数据
   - [x] 文本 / HEX 显示
   - [x] 清空接收区
3. **数据发送**
   - [x] 发送文本 / HEX 数据
   - [x] 可选发送换行（LF / CRLF）

------

### UI 要求

- [x] 单页工具型界面
- [x] 配置区 / 接收区 / 发送区
- [x] 简洁、不花哨

------

### 基本约束

- [x] 用户主动授权串口
- [x] 串口读写异步，不阻塞 UI
- [x] 异常情况给出提示

------

### 可选扩展

- [ ] 定时发送
- [ ] 快捷指令
- [ ] 数据导出
