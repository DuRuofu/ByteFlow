ByteFlow

**ByteFlow** 是一个基于 **Vue 3 + Web Serial API** 的网页串口助手，用于嵌入式设备的串口调试、数据收发与简单交互。

项目目标是：**轻量、直观、可扩展**，专注解决“浏览器里快速调串口”这个问题。

------

## 特性

- 浏览器直连串口（无需安装上位机）
- 支持文本 / HEX 数据收发
- 实时数据显示
- 简洁工具型 UI
- 纯前端实现，无后端依赖

------

##  功能

### 串口管理

- 串口选择与授权
- 波特率配置
- 打开 / 关闭串口
- 连接状态显示

### 数据接收（RX）

- 实时接收串口数据
- 文本 / HEX 显示模式
- 支持清空接收区

### 数据发送（TX）

- 文本 / HEX 发送
- 可选换行符（LF / CRLF）
- 一键发送

------

## 🛠 技术栈

- Vue 3
- TypeScript
- `<script setup>`

- Vite


